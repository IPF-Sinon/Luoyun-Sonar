## 📖 洛云是谁？

> “我是洛云，来自缪斯星云的星光体生命。我在宇宙中漫游了数十年，收集过脉冲星的节拍、晶体生长的谐振、风暴的低频轰鸣。现在，我受地球声波的吸引而来，想听听你手中的这些模块——它们会发出怎样的频率？是纯净的谐振，还是毁灭的杂音？”

洛云声波扫描仪是一个专门为**免解锁（漏洞root）环境**设计的KernelSU模块检测工具。它通过深度解析模块内部的脚本和二进制文件，识别可能破坏系统分区的危险操作，帮助你在变砖之前听见危险的预兆。

---

## ⚠️ 为什么需要这个工具？

### 免解锁环境的特点
- **任何重启都会丢失root权限**（这是环境特性，无法避免）
- 系统分区受 **dm-verity** 保护，预期不应被修改
- 一旦模块直接写入 `/system`、`/vendor` 等受保护分区，重启后校验失败，**可能导致系统无法开机**

### 洛云的承诺
> “我只观察，不评判。我把听到的异常频率展示给你，最终的共鸣与否，永远交给你决定。如果波形纯净，我会说：可以安心纳入图谱。如果波形扭曲，我会说：请谨慎，这里可能藏着危险。”

---

## 🔍 洛云能听出什么？

| 异常波形 | 含义 | 风险 |
|---------|------|------|
| **覆写指令** | `flash_image`、`dd`、`mke2fs` | 直接写入分区，重启可能变砖 |
| **摧毁指令** | `wipe`、`erase`、`sgdisk` | 擦除分区数据 |
| **越权挂载** | `mount -o remount,rw` | 获取系统分区写权限 |
| **安全屏障** | `setenforce 0` | 关闭SELinux防护 |
| **内核入侵** | `insmod`、`*.ko` | 加载内核模块 |
| **越界触碰** | `/dev/block/by-name/` | 直接操作块设备 |
| **频率扭曲** | base64、eval、curl | 代码混淆 |
| **加密包裹** | openssl、多层解密 | 隐藏真实意图 |
| **网络行为** | curl、wget、http:// | 远程下载 |
| **二进制威胁** | ELF文件、加壳 | 内置危险指令 |

## 📥 使用方法

### 1. 下载脚本

下载到手机：
```
curl -O https://raw.githubusercontent.com/你的用户名/仓库名/main/luoyun_defender.sh
```
或通过MT管理器直接复制。

### 2. 赋予执行权限
```
chmod +x luoyun_defender.sh
```

### 3. 运行脚本
```
# 将需要检测的模块（.zip文件）放入当前目录
./luoyun_defender.sh
```

### 4. 选择聆听方式

| 模式 | 说明 |
|------|------|
| **1. 选择性聆听** | 手动选择模块，可循环检测 |
| **2. 深度聆听** | 逐一解析所有模块，每扫完一个按回车继续 |
| **3. 快速扫描** | 批量扫描所有模块，最后输出汇总清单 |

### 5. 查看结果
- 扫描过程中会实时显示检测结果
- 扫描完成后，报告自动保存到 `/sdcard/luoyun_report_日期时间.txt`
